# Simulación del campo magnético del levitador

Visualización interactiva (HTML autocontenido, abrir en cualquier navegador) de cómo se mueve el campo
alrededor de las bobinas y cómo reaccionan las corrientes de los 4 PID cuando el imán cambia de lugar.

- `campo_levitador.html`: simulación interactiva (arrastra el imán, cambia la altura de levitación 25–35 mm, modo automático).
- `campo_levitador_720p.mp4`: video de 24 s para la presentación.

Modelo ilustrativo: superposición de dipolos (bobinas de 652 espiras, imán Ø25.4×2.1 mm, ≈1.1 A·m²).
Las corrientes de equilibrio corresponden a las de la simulación 3D del proyecto (≈0.7–0.95 A según la altura).
No es un cálculo de elementos finitos; sirve para explicar el comportamiento.
