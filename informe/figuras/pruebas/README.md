# Fotografías y capturas de las pruebas prácticas

Esta carpeta está reservada para las imágenes del montaje físico. Aún no se han cargado.

Cuando estén disponibles, guárdalas aquí con estos nombres (formato `.jpg`, o `.png` para capturas de pantalla) y quedarán listas para referenciarse desde el informe y el README:

| Archivo | Contenido |
|---|---|
| `montaje_fisico.jpg` | Fotografía general del circuito armado (protoboard o placa) |
| `medicion_diferenciador.jpg` | Toma de voltaje a la salida del diferenciador de error (U1) |
| `medicion_proporcional.jpg` | Toma de voltaje a la salida de la etapa P (U2) |
| `medicion_integral.jpg` | Toma de voltaje a la salida de la etapa I (U3) |
| `medicion_derivativo.jpg` | Toma de voltaje a la salida de la etapa D (U4) |
| `medicion_sumador.jpg` | Toma de voltaje a la salida del sumador (U5), rango 1 V a 3 V |
| `medicion_divisores.jpg` | Voltajes de los divisores con buffer: `V_ref` (U6) y `V_off` (U7) |

Recomendaciones para que la imagen sirva como evidencia: que se vea el display del multímetro u osciloscopio y el punto del circuito donde se mide, e indicar en el nombre o en una nota el caso (error mínimo, medio o máximo) cuando se tomen varias fotos de una misma etapa (por ejemplo `medicion_sumador_max.jpg`).
